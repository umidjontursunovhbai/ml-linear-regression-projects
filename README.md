# ML Linear Regression Projects

This folder contains 3 simple Machine Learning / Linear Regression projects.

## Projects

1. `01-yearly-salary`
   - Dataset: Yearly Salary
   - Feature: `YearsExperience`
   - Target: `Salary`

2. `02-students-performance`
   - Dataset: Students Performance in Exams
   - Feature: `gender`
   - Target: `math score`

3. `03-insurance`
   - Dataset: Insurance
   - Feature: `bmi`
   - Target: `charges`

## How to use

Open this whole folder in VS Code:

```bash
code /home/ubuntu/Public/ml-linear-regression-projects
```

For each project:

1. Put the Kaggle CSV file inside the project's `data/` folder.
2. Open the notebook.
3. Run cells from top to bottom.
4. Check MAE, MSE, R2 Score, and R2 Percentage.
5. Update README with final results.
