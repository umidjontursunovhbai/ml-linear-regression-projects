# Yearly Salary Linear Regression

## Dataset

I used the Yearly Salary dataset from Kaggle. The goal is to predict salary based on years of experience.

## Data Cleaning

The dataset was checked for missing values and duplicate rows. There were no missing values or duplicates.

## Features and Target

- Feature: `YearsExperience`
- Target: `Salary`

## Model

I used a Linear Regression model from scikit-learn. The dataset was split into training and testing data using an 80/20 split.

## Results

- MAE: 6286.45
- MSE: 49830096.86
- R2 Score: 0.9024
- R2 Percentage: 90.24%

## Conclusion

The model performed well. The R2 score was 90.24%, which means the model can predict salary quite well using years of experience.
